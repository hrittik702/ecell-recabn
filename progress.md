# Project Progress: E-Cell RECABN

## Project Overview
A modern, responsive React-based single-page application built for E-Cell RECABN. The project leverages Vite for fast builds, Tailwind CSS for styling, and GSAP for advanced animations and scrolling effects.

## Current Architecture
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP (GreenSock Animation Platform) with ScrollTrigger & React Tilt
- **Icons**: Lucide React

## Implemented Components
The main application structure (`App.jsx`) combines several modular components into a cohesive single-page layout:

- **Global Effects**:
  - `MouseFollower.jsx`: Custom interactive cursor effect.
- **Layout**:
  - `Navbar.jsx`: Top navigation bar.
  - `Footer.jsx`: Page footer.
- **Page Sections**:
  - `Hero.jsx`: The primary landing section with engaging visuals.
  - `About.jsx`: Details about the E-Cell's mission and vision.
  - `Events.jsx`: Showcases upcoming and past events.
  - `Timeline.jsx`: A timeline representation of milestones or history.
  - `Team.jsx` & `TeamCard.jsx`: Section dedicated to introducing the team members.
  - `Contact.jsx`: Contact information and outreach form.

## Data Management
- Static content and configuration data are stored centrally in `src/data/constants.js`.
